> 结论：在 v2 桌面客户端基础上，增量约 **12–16 小时**；如果还没有桌面端、单独做一个 Windows 小工具，约 **18–24 小时**。

## 1. 已确认的需求（2026-10-31）

| 项目 | 确认结果 |
|---|---|
| 计时起点 | **客户端连续运行 45 分钟** |
| 客户端关闭后 | **仍要提醒** |
| 提醒通道 | **微信（PushPlus）** |
| 与番茄钟的关系 | **共用同一个计时源** |
| 本期是否做 | **不做，记录到 v2** |

## 2. 这个需求意味着什么

「客户端关掉后还要提醒」决定了：**不能只靠客户端本地计时**。

必须这样做：

1. 客户端启动 → 调 `POST /api/sitting/start`，后端建一条「坐着会话」；
2. 客户端每 60 秒发一次心跳；
3. 后端后台任务每 30 秒检查：`started_at + 45 分钟 <= now` 且未提醒 → PushPlus 发微信 → 标记 `reminded_at`；
4. 客户端关闭后，后端**继续计时**，第一次 45 分钟提醒照发；
5. 如果 10 分钟没有心跳，说明人可能已经走了：**只发第一次，不再每 45 分钟重复**；
6. 客户端重新打开时，可以续上或新开一条会话（v2 设计时定）。

## 3. 数据与接口

| 对象 | 说明 |
|---|---|
| `sitting_sessions` | `id` / `user_id` / `device_id` / `started_at` / `last_heartbeat_at` / `reminded_at` / `ended_at` |
| `POST /api/sitting/start` | 客户端启动时调用 |
| `POST /api/sitting/heartbeat` | 每 60 秒一次 |
| `POST /api/sitting/stop` | 正常退出时调用（可选） |
| `GET/PUT /api/sitting/settings` | 45 分钟阈值、开关、稍后提醒 |

```
客户端启动
  → POST /sitting/start（后端记 started_at）
  → 每 60s heartbeat
  → 后端 45 分钟到点 → PushPlus → reminded_at
  → 客户端关闭：心跳停，但后端仍保留会话，到点照样发一次
```

复用 A3 已经做好的 `push_channels` + PushPlus 适配器，不重复造。

## 4. 与番茄钟共用计时的坑

「共用时间」听起来简单，但 25/5 番茄钟有一个冲突：

- 25 分钟专注 + 5 分钟休息 = 30 分钟一个循环；
- 如果 5 分钟休息就重置久坐计时，**45 分钟永远到不了**；
- 如果 5 分钟休息不重置，那「久坐」的语义又不对。

v2 设计时建议二选一：

| 方案 | 规则 | 效果 |
|---|---|---|
| **按长休息重置** | 只有 ≥10 分钟的休息才重置；5 分钟短休息不算 | 45 分钟能触发，符合「连续坐」 |
| **按累计专注** | 累计专注 45 分钟触发，短休息不清零 | 和番茄钟统计一致，但「坐」的语义弱一点 |

推荐**按长休息重置**；具体在 v2 做之前定。

## 5. 工作量拆分

### 5.1 已有 v2 桌面客户端，增量

| 任务 | 工时 |
|---|---|
| `sitting_sessions` 表 + start/heartbeat/stop 接口 | 3–4h |

| **合计** | **12–16h** |

### 5.2 没有桌面端，单独做

- 一个 Windows 小工具：托盘 + 定时 + 心跳 + 设置 + 打包 ≈ 12–16h
- 加上后端会话和推送 ≈ 6–8h
- **合计 18–24h**

### 5.3 只做网页弹窗（不满足本需求）

- 4–6h，但关掉浏览器就没了，**和「客户端关闭后仍提醒」冲突**，不推荐。

## 6. 为什么本期不做

1. 它依赖桌面客户端；Web 端关掉浏览器就提醒不到。
2. 当前 8 周已经 132 小时；再加 12–16 小时会到 144–148 小时，周均 18 小时以上。
3. 它和桌面悬浮球、番茄钟是同一套「陪伴」能力，放 v2 一起做更省事。

## 7. v2 验收标准（先记着）

- [ ] 客户端启动后第 45 分钟，微信收到提醒
- [ ] 只关窗口、进程还在托盘时，仍能收到
- [ ] 完全退出客户端后，后端仍在第 45 分钟发一次
- [ ] 无心跳 10 分钟后，不再每 45 分钟重复
- [ ] 与番茄钟共用计时；长休息（≥10 分钟）后重新计时
- [ ] 10 次测试至少 9 次到达；重复推送 0
- [ ] 开关关闭后 0 次
