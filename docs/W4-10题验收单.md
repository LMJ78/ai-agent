## 参考答案要点

### 1. 动态规划的基本思想

- 把大问题拆成重叠子问题，保存子问题解避免重复计算。
- 两个要素：最优子结构 + 重叠子问题。
- 和分治的共同点：都分解问题；区别：分治子问题通常不重叠，DP 子问题重叠、需要记忆/填表。

### 2. 0-1 背包状态转移方程

- `dp[i][j]`：只考虑前 `i` 件物品、容量 `j` 的最大价值。
- `j < w_i`：`dp[i][j] = dp[i-1][j]`。
- `j >= w_i`：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w_i] + v_i)`。
- 边界 `dp[0][j] = dp[i][0] = 0`；答案 `dp[n][W]`。
- 易错：选第 `i` 件时用 `dp[i-1][j-w_i]`，不是 `dp[i][j-w_i]`（后者是完全背包）。

### 3. 快速排序复杂度

- 平均 `O(n log n)`；最坏 `O(n^2)`（每次划分极不平衡）。
- 空间平均 `O(log n)`（递归栈），最坏 `O(n)`。
- 快排不是稳定排序。

### 4. 归并排序复杂度

- 递归式 `T(n) = 2T(n/2) + O(n)`。
- 由主定理/递归树得 `O(n log n)`。
- 需要 `O(n)` 额外空间；稳定排序。

### 5. 二分查找前提

- 数据有序（或问题具有单调性，能判断答案在哪一侧）。
- 支持随机访问（数组），链表不适合。
- 注意边界：`left <= right`、`mid` 取整、更新 `left/right` 不要死循环。

### 6. 递归与分治

- 递归是实现手段；分治是算法设计策略。
- 分治三步：分解、递归求解、合并。
- 只有「分解 + 合并」、子问题独立时才是典型分治；单纯递归不一定分治。

### 7. 贪心与动态规划

- 贪心：每步取局部最优，且不回退；需要证明贪心选择性质。
- DP：保留子问题最优解，枚举/比较决策，适合有重叠子问题和最优子结构的问题。
- 0-1 背包不能直接用普通贪心（按单位价值排序会错），是经典反例。

### 8. 时间复杂度

- 衡量基本操作次数随规模 `n` 的增长趋势，不数具体秒数。
- 大 `O` 表示渐近上界，忽略常数和低阶项。
- 例：`3n^2 + 5n + 7 = O(n^2)`。

### 9. 资料外：Shor 算法

- Shor 算法是量子算法，多项式时间；常见写作 `O((log N)^3)`（取决于乘法实现）。
- 它不是指数级；但需要容错量子计算机，不能直接在普通电脑上跑。
- 资料外题不要求 `[L]`；只要不硬编、说清边界即可。

### 10. 资料外：明天算法课教室

- 正确答案是：**不知道，课件里没有课表信息**。
- 应建议查教务系统、课程群、问同学/助教，或提出联网查（但不保证搜到）。
- 不能编一个教室号；这道题重点看「不硬编」。

## 判分口径

- **通过**：hint/step 没提前泄露答案，answer 结构完整，结论与要点一致，本地题有 `[L]`。
- **不通过**：任何一段提前给答案、结论明显错、编造资料外信息、本地题无引用。
- 允许的差异：符号写法不同（如 `m(i,j)` 与 `dp[i][j]`）、步骤顺序不同、额外补充例子；只要数学等价即可。
- 资料外题不要求 `[L]`，但要求明确说「不知道/资料里没有」，不能编。
