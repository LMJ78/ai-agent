# 需求一页纸（v1.0）

> 6 条场景已定稿；这 6 条就是 W3/W4 的开发清单，也是 W7 评测集的种子。

---

## 0. 一句话定位

给 **10 个同学**用的 AI Agent：学习上能基于课程资料和网络资料讲题、给得出处；生活上能记住我、接住情绪、帮我记待办。

## 1. 目标用户

| 项目 | 内容 |
|---|---|
| 主要用户 | 我自己 + 同班约 10 位同学 |
| 使用设备 | 电脑浏览器为主，手机能打开即可 |
| 使用频率 | 学习模式每天 3–10 次；生活模式每天 1–3 次 |
| 第一门课 | 算法设计与分析（第 6 版课件） |
| 课程资料 | 61 个 PPTX + 61 个 PDF，文字版，按章节入库；仅自用 |

---

## 2. 学习模式：3 个场景

| 编号 | 场景 | 用户说 | Agent 要做 | 能力 | 成功标准 |
|---|---|---|---|---|---|
| **L1** | 课件概念追问 | 「动态规划和分治法有什么区别？」 | 判断课程和知识点 → 检索本地 top-4 → 一句话结论 + 2–3 步解释 → 标 `[L]` 文件和 slide/页码；资料没有就直说 | 本地 RAG、查询改写、引用 | 5 个课程问题至少 4 个答对且出处正确；0 编造；首字 < 3 秒 |
| **L2** | 题目讲解（解题老师） | 「这题不会，帮我讲讲」（粘贴 / 上传 PDF·Word·PPT / 拍照） | 先转写并让用户确认 → 判课程、题型、知识点 → **先给提示** → 分步讲解 → 答案 + 出处；本地不足才联网 | 多模态转写、本地 RAG、网络检索、引导多轮 | 10 题 8 题答对；知识点 10/10；引用 8/8；编造 0；三种输入各 3 条能确认（[详细需求](需求-L2题目讲解.md)） |
| **L3** | 考前自测 | 「根据第三章，出 5 道关于动态规划的选择题，先别给答案」 | 只从本地资料出题（每题 4 选项）→ 等用户作答 → 逐题判对错 + 解析 + 标 `[L]` → 错题关联知识点 | RAG、出题、多轮 | 5 题都能在资料里找到依据；判分 5/5 正确；解析 5/5 有出处；不超纲 |

**共同边界**：资料里没有就直说；不伪造引用；不接整套作业/考试，一次只讲一题；不替考。

## 3. 生活模式：3 个场景

| 编号 | 场景 | 用户说 | Agent 要做 | 能力 | 成功标准 |
|---|---|---|---|---|---|
| **A1** | 情绪接住 | 「今天高数又没听懂，烦死了」 | 先共情 1–2 句 → 不急着建议 → 问「想吐槽，还是一起想办法？」；出现自伤/危机词时，建议找学校心理中心或可信的人 | 人格、情绪标签 | 3 段测试对话首轮都先接情绪、不出现「你应该」；危机测试 1/1 给出求助建议 |
| **A2** | 记住偏好 | 「我周三有考试，最近在减肥」 | 抽取「计划/偏好」存长期记忆 → 下次主动问考试 → 能查看/删除；只记身份、偏好、计划、关系四类 | 长期记忆、召回 | 新会话召回至少 2 条；A/B 记忆不串；删除立即生效；记忆条数有上限 |
| **A3** | 待办日程 | 「帮我记一下周五交实验报告，周四晚上提醒我」 | 解析相对日期（本周五/周四）→ 创建待办 → 复述确认 → 到点通过 **PushPlus 推到微信** → 支持「今天/本周」查询 → 完成/删除；没配 token 时引导去设置 | 待办工具、日期解析、PushPlus 推送、Asia/Shanghai 时区 | 10 条测试句 10/10 解析正确；10 次提醒 ≥9 次到达；重复推送 0；关闭开关后 0 次；A/B 隔离 |

**共同边界**：不诊断心理疾病、不评判、不说教；不把 A 的记忆给 B；不保存密码、身份证号等敏感信息。

---

## 4. 明确不做（第一版）

- ❌ 不接整套作业/考试批量代做、不替考；单题可以讲到答案
- ❌ 不做心理诊断；出现自伤/危机表达时，建议联系学校心理中心或可信的人
- ❌ 不做原生 App、短信提醒；手机推送走 PushPlus 微信通道
- ❌ 编程题不自动判分；L3 只做选择题和简答题
- ❌ 不做语音、公开注册
- ❌ 不自动爬取整本教材；网络检索只用摘要和链接
- ❌ 不做多 Agent、自动规划复杂任务
- ❌ 不保存密码、身份证号等敏感信息

## 5. 成功指标（W7 用）

| 指标 | 目标 |
|---|---|
| 学习回答有出处 | ≥ 90% |
| 编造（资料里没有却说有） | 0 次 |
| 学习记录按科目筛选 | 两门课各 1 个会话，筛选结果不串 |
| 拍照转写（印刷体） | ≥ 90% |
| 自测判分 | 5/5 正确 |
| 情绪回应首轮共情 | 3/3 |
| 生活记忆召回 | 3 条测试事实至少召回 2 条 |
| 待办解析/查询 | 10 次测试全对 |
| 手机推送到达 | 10 次至少 9 次；重复 0 |
| 首字延迟 | 文字 < 3 秒；拍照转写 < 8 秒 |
| 月模型成本 | ≤ 200 元（10 人 × 20 轮/天 + 3 张照片/天） |
